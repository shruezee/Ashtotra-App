# Ashtotra

**A devotional reading app:** a picture list of Hindu deities that opens each Ashtottara (108 names) prayer as a PDF, available in several Indian languages.

## What it demonstrates

- Building the deity list dynamically from the documents bundled with the app
- Switching language with a segmented control (Plain English, Kannada, Devanagari, Telugu, Tamil, Gujarati) and showing the matching PDF with **PDFKit**
- Matching each prayer to its deity image, with a default image as a fallback
- A banner ad integration with separate test and production ad units
- Unit tests for the document lookup logic

## Running it

Run `pod install`, then open `Ashtotra.xcworkspace` in Xcode and run it on a simulator.
